# 05-framework-ui

Hytale modding component: framework-ui

## Installation

```xml
<dependency>
    <groupId>com.argonathsystems.framework</groupId>
    <artifactId>ui-framework</artifactId>
    <version>1.0.0-SNAPSHOT</version>
</dependency>
```

## Building

```bash
mvn clean install
```
